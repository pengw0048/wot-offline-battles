World of Tanks 0.9.22.0.1 #1513 LAN/offline package
===================================================

Close the game, then extract the contents of this folder directly into the
directory that contains WorldOfTanks.exe. It contains:

  mods\0.9.22.0.1\org.peng.offline_lan_0922_<version>.wotmod
  mods\configs\offline_lan_0922\config.json
  mods\configs\offline_lan_0922\navgraphs\
  mods\configs\offline_lan_0922\foliage\
  mods\configs\offline_lan_0922\destructibles\
  WoT-0.9.22-LAN-Server.exe
  offline_worker_starter.exe
  START_OFFLINE_0922.bat
  START_LAN_CLIENT_0922.bat
  START_SIMULATION_WORKER_0922.bat
  tools\AUTHORITY_WORKER_PROBE.md
  tools\authority_worker_probe_supervisor.py
  tools\WINDOWS_MIGRATION_ACCEPTANCE.md
  tools\windows_migration_acceptance.ps1

Move every older org.peng.offline_lan_0922*.wotmod out of
mods\0.9.22.0.1 before copying this version. The normal host path is the
desktop launcher's Online tab: click Start LAN room, then start the host game.
A joining PC enters the host address in the same tab. START_OFFLINE_0922.bat is
a diagnostic visible-client entry point only; it does not start the Rust server
or hidden native-world oracle.

Start the client with START_OFFLINE_0922.bat. It passes the #1513-supported
preferences leaf `preferences.offline-player.xml`, so it never reads or writes
the normal `preferences.xml`. The first isolated start may ask for the EULA
and display settings again.

Play
----

1. In the launcher, select LAN and click Start LAN room. It starts the LAN
   server and its one hidden native-world oracle; a room never uses a visible
   player client as a fallback authority. Start the client without logging
   into an online account. On a fresh profile, accept the stock EULA once.
2. Fit a tank in the garage and click Battle!. The client joins the LAN room.
   The battle runs the tank the garage fitted, with its modules, health, armour
   and gun.
3. Every player sees the waiting room, drawn over the stock battle queue
   screen. The first player is the room host: the host selects a standard map
   with < and >, then clicks START BATTLE. LEAVE closes the room and returns
   you to the garage.
4. The room host chooses 1 through 15 total tanks for each team, including
   human players. Movement and firing unlock when the countdown reaches
   battle.
5. After a team is eliminated the round freezes, every connected player
   returns to the waiting room after five seconds, and the stock battle-results
   notification is requested. A player who left after dying receives the same
   durable result on reconnect.

Only standard battles are supported. In this client the internal name of
standard battle is `ctf`; assault and encounter maps are excluded.

The garage
----------

Every vehicle in your client is owned, and every module in its own tech tree is
unlocked. Each vehicle arrives with its top chassis, turret, gun, engine, radio
and fuel tank, plus an automatic fire extinguisher, a large first aid kit and a
large repair kit. Every item costs nothing.

Change modules, optional devices, consumables, shells, camouflage and crew
skills as you like. Each change is written to
mods\configs\offline_lan_0922\garage_state.json, so the garage survives a
restart. Crew skills, optional devices and consumables move the same values the
garage parameters panel shows, and the battle uses those values.

The Launcher's Tools tab can also edit vehicle data directly. A vehicle data
profile is a named set of Packed XML field changes (health, damage,
penetration, armour, speeds, reload and more) made in the Launcher's editor; it
never changes scripts.pkg. In single player the selected profile is active only
for that session and removed when the game closes. In a LAN room the host's
profile is pinned for the whole room: the server shares the modified package
members with every joining Launcher, which installs the same temporary overlay
before the game starts, so the host client, the hidden oracle and every joiner
run identical modified vehicle data. A room whose profile changed after it
started must be restarted first.

Requirements
------------

- The exact Chinese HD client 0.9.22.0.1 #1513.
- The x64 Rust LAN server and hidden native-world oracle from the same
  repository revision, on the host PC. A LAN room listens on 0.0.0.0:28782
  and supports up to 30 players. A single-player round also uses both.

Manual diagnostic entry points
------------------------------

The Launcher normally starts the Rust LAN server, mandatory hidden oracle and
visible client in the required order. For diagnostics only, start the server, then
START_SIMULATION_WORKER_0922.bat, then START_OFFLINE_0922.bat. The hidden
oracle supplies version-locked BigWorld collision and geometry observations
and does not occupy a player slot. The Rust process owns the room, portable
simulation, combat, replication and results; without the oracle it fails
closed instead of assigning authority to a visible player.

Troubleshooting
---------------

- No connection: check the server address, the host firewall and that the
  server window is still open.
- `unsupported compression type`: an older wotmod is still present. Keep only
  the org.peng.offline_lan_0922 wotmod from this package.
- The client keeps its own files. Your saved address, account state, garage and
  configuration survive a reinstall.
- If a crash leaves this mod stuck at login, close the game, rename
  mods\configs\offline_lan_0922\config.json as a backup, and extract this ZIP
  again. This restores the default configuration without deleting the garage,
  account progress, vehicle-data overrides or battle results. To reset every
  ordinary offline save manually, delete config.json, server_endpoint.json,
  account_state.json, garage_state.json and postbattle_state.json while the
  game is closed, then extract this ZIP again. Vehicle-data overlays are
  separate and are not removed by that reset.
- Bot tracks and road wheels do not turn. A broken enemy track therefore has no
  visual cue; read the damage panel instead.
- The client is 32-bit but its executable is large-address-aware, so on 64-bit
  Windows it can use up to about 4 GB rather than the ordinary 2 GB ceiling.
  That address space is still finite: a very long session can run out of memory
  and exit. Restart the client between long sessions.
- One of the 680 vehicles in this client, germany:G138_VK168_02_Mauerbrecher,
  ships no models. The garage and the bot lineups skip it.

Optional authority-worker probe
-------------------------------

The diagnostic probe is disabled by default and does not change normal play.
To measure draw-on, draw-off and a safely supervised hidden-window stage, read
tools\AUTHORITY_WORKER_PROBE.md. It explains the opt-in config entry, the
required windowed mode and how to run the included Python 3 supervisor. Disable
the probe again after collecting its report.
