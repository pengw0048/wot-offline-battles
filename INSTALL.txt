World of Tanks 0.9.22.0.1 #1513 LAN/offline package
===================================================

This is the project's only supported and installable client package. It carries
no payload, installer or runtime for any earlier client line.

Close the game, then extract the contents of this folder directly into the
directory that contains WorldOfTanks.exe. It contains:

  mods\0.9.22.0.1\org.colorfulmeans.offline_lan_0922_<version>.wotmod
  mods\configs\offline_lan_0922\config.json
  mods\configs\offline_lan_0922\navgraphs\
  mods\configs\offline_lan_0922\foliage\
  mods\configs\offline_lan_0922\destructibles\
  START_OFFLINE_0922.bat
  START_SIMULATION_WORKER_0922.bat
  tools\AUTHORITY_WORKER_PROBE.md
  tools\authority_worker_probe_supervisor.py

Move every older org.colorfulmeans.offline_lan_0922*.wotmod out of
mods\0.9.22.0.1 before copying this version. Start the LAN server on one PC,
then edit mods\configs\offline_lan_0922\server_endpoint.json when the server is
not 127.0.0.1:28782. That user-owned file is never shipped in this package.

For a manual diagnostic start, START_OFFLINE_0922.bat uses
`--config engine_config.offline-player.xml`, whose isolated preferences leaf
is `playerprefs.xml`. The hidden worker uses its separate `workerprefs.xml`.
Neither replaces the normal `preferences.xml`. The first isolated start may
ask for the EULA and display settings again.

Play
----

1. On the host PC, select Host a LAN battle in the launcher. Other players
   select Join a LAN battle and enter the host's address. Click Start game.
   The host launcher starts the server and its one hidden simulation worker;
   a room never uses a visible player client as a fallback authority. Start
   without logging into an online account. On a fresh profile, accept the
   stock EULA once. Single player creates a separate local room.
2. Fit a tank in the garage and click Battle! or Create Platoon. Both join
   the configured LAN room; Create Platoon does not use retail invitations.
   The battle runs the tank the garage fitted, with its modules, health, armour
   and gun.
3. Every player sees the waiting room, drawn over the stock battle queue
   screen. The first player is the room host. Select the same team to play
   together. RANDOM MAP lets the server pick;
   MAP opens the client's own map window, where the host picks a standard map
   and a battle time and confirms. The room comes back with that choice, and
   START BATTLE starts it. LEAVE closes the room and returns you to the
   garage. BOT TIER picks which vehicle tiers the Bots bring, and BOT SKILL
   picks how good their gunners are: Easy, Relaxed, Pub mix, Hard or Brutal.
   Only the host sees those two rows.
4. The server fills each team to WOT_0922_TEAM_SIZE total tanks, including
   human players (1 through 15, default 15). Set that environment variable in
   the batch file that starts the server. Movement and firing unlock when the
   countdown reaches battle.
5. After a team is eliminated the round freezes, every connected player
   returns to the waiting room after five seconds, and the stock battle-results
   notification is requested. A player who left after dying receives the same
   durable result on reconnect.

Standard battles and LAN training rooms use standard maps. In this client the
internal name of standard battle is `ctf`; assault and encounter maps are
excluded. Choose Training to open a room without standard matchmaking. The
host selects the map, teams and duration, optionally enables Bots, then starts.
Training gives no rewards, medals or mission progress and repairs are free;
spent ammunition and consumables are still charged normally.

The garage
----------

In a fully unlocked save every vehicle in your client is owned, and every
module in its own tech tree is unlocked. Each vehicle arrives with its top
chassis, turret, gun, engine, radio and fuel tank, plus an automatic fire
extinguisher, a large first aid kit and a large repair kit. A new-account save
starts with starter vehicles. Purchases use the displayed currency and price.

Armory Special Offers includes the five retired vehicles and compatible
vehicles from the first official bond shop (2019). The retired prices are
offline settings: Aufkl. Panther 6000, SU-122-54 12000, Object 430B,
Object 263B and Waffentrager E 100 15000 bonds each. Every offer includes a
garage slot and 100% crew. Offers use the native Shop rows and vehicle artwork,
with bond prices. Owned vehicles follow the available ones and cannot be
purchased again. The offer filters are separate from the regular Shop filters.

Personal Reserves uses the native inventory, missions and purchase tabs with
44 historical bonus/duration combinations across four resource types. Active
reserves appear in the three slots in both the window and account popover.
Purchases and activation produce system messages.
Close or Escape returns to the garage. Up to three different types may be
active together. The Missions tab opens three daily offline goals, randomly
selected from fixed-reward templates at 00:00 UTC (08:00 Beijing time).
Reopening or restarting cannot reroll that day's selection or claim it twice.
An existing fixed set keeps its progress until the next reset. Reserve prices
and these daily goals are custom offline rules. Completed daily goals appear
in the lower-left battle-result area, with one combined reward popup per
battle and a system message. Regular campaign missions now settle supported
battle conditions and mission rewards separately. The launcher can edit all
300 completion states, automatically completing required earlier tasks without
honors. Missing rewards arrive on the next garage load. Female crew rewards
use the game's own nationality, vehicle and role chooser. Clearing any main
completion resets its chain's final and all five classes in every later
operation, withdrawing the corresponding rewards and dependent operation
rewards. Clearing honors alone changes no other task and withdraws only its
additional rewards. Campaign badges and their equipped selection are removed
when their requirements are no longer met. Failed withdrawals leave the old
progress and property unchanged and report the reason in the editor and system
messages. Only unexpired mission-earned premium time can be reclaimed.

Reward tanks are withdrawn, returning crew and fitted items to storage. Before
any tank grant, an already owned vehicle instead receives its full original
credit value, without the sale discount or custom bond-shop price. Cancellation
reclaims that recorded compensation rather than the previously owned vehicle.
This is an explicit offline policy. Successful withdrawal allows a later
completion to grant the reward again. The original battle TAB shows the active
personal mission for that vehicle; the battle-result quest area and system
messages show progress and actual rewards. Launcher changes queue their reward
and withdrawal messages for the next garage load.
Orders come from mission honors rewards; the launcher has no order-count input.
The balance is derived from honored-final claims minus current pledges; old
manually supplied extras are removed. Four operations can earn 20 orders in
total. Cancelling and redoing missions or reclaiming pledges cannot exceed
those earned entitlements.

The badge slot in the account popover opens the native badge page. Acquired
badges can be selected, and ownership and selection are saved with the account.
The launcher can edit ownership using the installed client's badge catalogue.

Premium uses the original 360, 180, 30, 7, 3 and 1-day options.
An active premium account now applies the legacy 50% credit and experience
bonus to actual battle income, including crew training. Native results show
the separate standard and premium columns. Each tank's first standard-battle
victory of the day earns double experience; the reset is 00:00 UTC, and the
garage's first-win indicators refresh when the account returns to the lobby.
Each garage vehicle card uses the native x2 badge until that tank wins, then
shows its ordinary artwork until the next reset. Losses and draws do not
consume the bonus. The native vehicle tooltip shows the daily multiplier too.
Premium eligibility is fixed at battle start. These rules apply to newly
settled battles; previously saved results are not recalculated or paid again.
Friendly-fire result labels come from the installed client localization;
credits include penalty and compensation, while XP includes penalty only.
Voice chat is unavailable offline because the client has no Vivox account
service; sound settings do not repeatedly try to initialize it.

A complex optional device is destroyed when you take it off, unless you pay
the removal price -- the same choice the game gives you.

Shells are spent in battle and cost credits to replace, and so is each
consumable you use, so resupplying after a battle is part of what it cost you.

A battle leaves your tank as damaged as it ended, and repairing it costs
credits. The garage shows the damage and the repair button pays for it. The
damage is saved, so restarting the game does not repair anything.

Recruit crew members from the three schools the game offers. In a new-account
save the 75% school costs 20000 credits and the 100% school costs 200 gold; in
a fully unlocked save all three are free.

Sell a vehicle and its crew can go to the barracks instead of being dismissed,
as long as there are free berths. A crew member in the barracks can take a seat
again in a vehicle of the type they were trained for. Retraining moves a crew
member to another vehicle, at the same three schools, one at a time or the
whole crew at once.

Change modules, optional devices, consumables, shells, camouflage and crew
skills as you like. Each change is written to the selected save, so the garage
survives a restart. Crew skills, optional devices and consumables move the same
values the garage parameters panel shows, and the battle uses those values.

Saves
-----

The Launcher's Saves tab keeps as many independent saves as you want. Each one
has its own garage, crew, account settings and battle results, and the selected
save is the one the game starts with. Saves live in
%APPDATA%\Wargaming.net\WorldOfTanks\offline_lan_0922\saves\<save>\. A save you
made in an older build keeps working: its files move into the default save the
first time this build starts.

"Open save folder" opens that folder, "Back up save..." writes the whole save
to one ZIP file, and "Restore save..." puts a backup back into the selected
save. Close the game before restoring one. The files being replaced are kept in
a pre-restore folder inside the save, so restoring the wrong backup is
recoverable. The game also keeps its own copies beside each state file: a
.backup1 to .backup3 copy of the file as an earlier session found it, and a
.rejected- or .shrunk- copy of any file it refused to load or was about to
shrink. Those copies are plain JSON files you can copy back over the live one
while the game is closed.

When you create a save the Launcher asks which account it starts from, and the
answer cannot be changed later. "Fully unlocked" is the garage this mod always
had: every vehicle, module and consumable already owned. "New account" starts
like a real World of Tanks account: the tier 1 starter tanks, 100000 credits,
30 garage slots, and an unresearched tech tree. You earn credits and experience
in battle and research and buy everything else in the garage, at the prices
this client ships.

The Account tab shows the selected save's credits, gold and free experience and
lets you set them. Gold cannot be earned offline, so that is where a save gets
it. Start a save in the game once before editing it, and close the game first.

The Shop tab sells every vehicle the client prices in gold, including the
reward tanks the game's own shop never sold. Buying one takes gold from the
selected save; the tank appears in the garage the next time the game starts
that save. A save from an older version must be started once before the shop
can sell to it, because only the game can tell the launcher what it owns.

Vehicle data profiles are not part of a save. They change the client's shared
vehicle catalogue for a whole room, so they stay with the installation.

The Launcher's Tools tab can also edit vehicle data directly. A vehicle data
profile is a named set of Packed XML field changes (health, damage,
penetration, armour, speeds, reload and more) made in the Launcher's editor; it
never changes scripts.pkg. In single player the selected profile is active only
for that session and removed when the game closes. In a LAN room the host's
profile is pinned for the whole room: the server shares the modified package
members with every joining Launcher, which installs the same temporary overlay
before the game starts, so the host client, the hidden worker and every joiner
run identical modified vehicle data. A room whose profile changed after it
started must be restarted first.

Requirements
------------

- The exact Chinese HD client 0.9.22.0.1 #1513.
- The LAN server from the same repository revision, on one PC. It always
  listens on 0.0.0.0:28782 and supports up to 30 players. A single-player round
  also uses it.

Manual diagnostic entry points
------------------------------

The Launcher normally starts the LAN server, mandatory hidden worker and
visible client together. For diagnostics only, start the server, then
START_SIMULATION_WORKER_0922.bat, then START_OFFLINE_0922.bat. The hidden
worker does not occupy a player slot; without it the room cannot start a
battle.

Troubleshooting
---------------

- No connection: check the server address, the host firewall and that the
  server window is still open.
- `unsupported compression type`: an older wotmod is still present. Keep only
  the org.colorfulmeans.offline_lan_0922 wotmod from this package.
- The client keeps its own files. Your saved address, account state, garage and
  configuration survive a reinstall.
- If a crash leaves this mod stuck at login, close the game, rename
  mods\configs\offline_lan_0922\config.json as a backup, and extract this ZIP
  again. This restores the default configuration without deleting the garage,
  account progress, vehicle-data overrides or battle results. To reset every
  ordinary offline save manually, delete config.json and server_endpoint.json
  in mods\configs\offline_lan_0922, then delete account_state.json,
  garage_state.json, postbattle_state.json and the saves folder under
  %APPDATA%\Wargaming.net\WorldOfTanks\offline_lan_0922 while the game is
  closed. Extract this ZIP again afterwards. Vehicle-data overlays are
  separate and are not removed by that reset.
- Bot tracks and road wheels do not turn. A broken enemy track therefore has no
  visual cue; read the damage panel instead.
- The client is 32-bit but its executable is large-address-aware, so on 64-bit
  Windows it can use up to about 4 GB rather than the ordinary 2 GB ceiling.
  That address space is still finite: a very long session can run out of memory
  and exit. Restart the client between long sessions.
- One of the 680 vehicles in this client, germany:G138_VK168_02_Mauerbrecher,
  ships no models. The garage and the bot lineups skip it.

Optional authority-worker probe
-------------------------------

The diagnostic probe is disabled by default and does not change normal play.
To measure draw-on, draw-off and a safely supervised hidden-window stage, read
tools\AUTHORITY_WORKER_PROBE.md. It explains the opt-in config entry, the
required windowed mode and how to run the included Python 3 supervisor. Disable
the probe again after collecting its report.
