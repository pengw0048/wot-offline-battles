World of Tanks 2.3.1.2 offline map bootstrap 0.1.2
=================================================

1. Remove earlier offline probe packages from:
     <World_of_Tanks>\mods\2.3.1.2\

2. Copy this file there:
     org.peng.offline_2312_avatar_arena_probe_0.1.2.wotmod

3. Run from the client root:
     win64\WorldOfTanks.exe --script-arg avatarArenaProbe --script-arg offline --script-arg spaces/01_karelia

The camera should appear above the team-one Karelia CTF spawn and face toward
the enemy base. In python.log, confirm that `camera_repositioned` contains
target X/Z `(382.000, 386.000)` and a terrain-derived Y value near 56.3.

This build still has no Vehicle or controls. It is the corrected map/Avatar
bootstrap used while the normal Account, battle-session, ArenaInfo/TeamInfo,
Vehicle appearance/physics, and AvatarInputHandler interfaces are being
connected.
