# 2026-09-14 物理测试构建

基于已发布 v0.8.0 的提交 `4b532dabe74f9a63ef880bb8286ad3c61aec742e`。

## 修正内容

- 侧滑在同一帧的悬挂求解之前积分，避免随后沿旧坡面强制降低车体高度。
- 碰撞分离后的零时间修正不再向下移动或额外赋予竖直速度；失去地面支撑后由世界 Y 轴重力继续积分。
- 悬挂向下探测范围依据真实高度和下落速度，不再随旧坡面向悬崖下方跳转。
- 高速坠落的合法位移不会再被固定 5 米的异常检查回滚。
- 旧物理回退路径不再把 0.8–2.5 米的支撑搜索范围当成每帧允许吸附的落差；窄沟仍要求两端支撑。
- 腾空时的硬车体碰撞消除撞入表面的速度分量，保留切向和坠落运动。
- 玩家及 Bot 的实际硬车体/场景碰撞接入世界碰撞伤害；采用接触法线方向的撞击速度，排除预测探测、平行擦碰和短时间重复结算。

## 测试范围

自动场景覆盖零时间侧向修正、30/120 Hz 下驶离平台、超过 5 米的单帧高速坠落、半米台阶、车体上部/侧面撞墙、擦边、玩家权威扣血队列及 Bot 血量。

本补丁沿用项目现有的世界碰撞伤害曲线和简化悬挂模型。测试环境不能运行 WoT 的 Windows 原生地图碰撞引擎，仍需要在实际客户端验证地图和手感。

## 安装与实测

完整解压测试包一次，运行 `wot-0.9.22-offline-battles.exe`，选择原来的 0.9.22.0.1 #1513 游戏目录并启动。

建议依次测试：缓慢驶离悬崖、侧滑离开崖缘、高速飞出坡顶、车头或车身撞岩壁，以及正常斜坡和窄沟。若还有卡入地形，导出新错误报告，并注明地图、车辆和大致发生时间；日志中的 `WORLD IMPACT` 可核对车体撞击是否已结算。
