# 2026-09-14 第二份物理测试构建

基于第一份测试包 `colorfulmeans-34795874227-1`，对应用户的 11:36 错误报告。

## 修正内容

- 翻车时启用从车体、炮塔碰撞包围盒取得的侧面和顶部接触点。倒扣时履带弹簧不再提供向上的推进力，车体和炮塔通过刚性接触支撑在地面上。
- 履带射线遇到铁路枕木缝隙、读到较低横梁时，重新探测实际轮组覆盖的范围。只有新射线仍找到原支撑层才继续使用它；驶离桥端后释放支撑并下落。
- 平地行驶时撞击建筑物只阻挡运动，不再扣血。腾空或坠落时的车体撞击仍使用原有伤害结算，坦克之间的撞击规则不变。
- 可破坏物匹配允许已知同一物体编号的变换数据相差一个取整单位。报告中已经出现编译位置与原生位置相差一毫米、导致物体被排除的问题。恢复后仍核对物体编号、原生类型、描述符和破坏条件。

## 验证和范围

新增场景覆盖 30/120 Hz 下的侧翻、倒扣、翻滚落地、车顶及炮塔接地、Bot 倒扣、桥面窄缝和下层横梁、驶离桥端，以及地面撞墙不扣血。原先的悬崖与腾空车体撞击回归继续保留。

已确认的可破坏物识别误差得到修正，但报告没有逐一指出每栋木屋和障碍物，不能据此确认所有不可破坏现象都有相同原因。需要实际客户端复测；如果仍有问题，请记录地图、目标位置或截图，并导出新报告。

此环境不能运行 WoT 的 Windows 原生地图引擎，自动场景验证不能替代游戏内验证。

## 使用

完整解压测试包一次，运行 `wot-0.9.22-offline-battles.exe`，选择原来的 0.9.22.0.1 #1513 游戏目录。启动器会安装这份测试包中的新补丁。

建议复测冻土铁路桥、翻车后车顶及侧面接地、平地撞建筑物，以及之前无法撞毁的木屋和障碍物。
