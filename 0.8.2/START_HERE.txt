World of Tanks 0.8.2 native bot physics experiment 1.8.59
=========================================================

This package does NOT contain the World of Tanks client. You must already have
a lawfully obtained Windows 0.8.2 client.

Read START_NATIVE_TEST_HERE.txt first. This package is a separate experimental
build and must not be merged with the stable or F6-probe folders.


CLIENT INSTALLATION (repeat on every PC that will play)
-------------------------------------------------------

1. Close World of Tanks.
2. Open the game folder, then open its res_mods folder.
3. Delete or move aside the old res_mods\0.8.2 folder.
4. Drag this package's complete 0.8.2 folder into the game's res_mods folder.

   The final entry file must be:

   <game folder>\res_mods\0.8.2\scripts\client\gui\mods\mod_offhangar.py

5. Start the game. A successful install goes directly to the offline garage.

For single-player offline battles, installation is complete. Select a tank and
click Battle!; no separate Python installation or server is required.


LAN SERVER (only one machine needs this)
----------------------------------------

1. Install a current Python 3 release:

   https://www.python.org/downloads/

   On Windows, enable "Add python.exe to PATH" in the Python installer.

2. Keep lan_battle_server.py, server_bot_ai.py and server_bot_navigation.py
   together in this folder.
3. Windows: double-click RUN_SERVER.bat.
   macOS: double-click RUN_SERVER.command, or run it from Terminal.
4. Allow TCP port 28782 through the server machine's firewall if prompted.
5. Leave the server window open while playing.

The expected startup line is similar to:

   LAN battle server listening on 0.0.0.0:28782 (... protocol=8, build=1.8.59-native-experimental-20260815)


JOIN THE SAME LAN BATTLE
------------------------

1. In every client's garage, open LAN SETTINGS in the upper-right.
2. Enter the LAN IP address of the machine running the server and port 28782.
3. Enable LAN Battle and save.
4. Click Battle! on every client that should join.
5. Confirm one JOIN line per client in the server window.
6. In the waiting room, choose a map and click START BATTLE.

Every client and the server must come from this same protocol-8/
build-1.8.59-native-experimental-20260815 package.


IF SOMETHING DOES NOT LOAD
--------------------------

- Make sure the game was closed while copying files.
- Make sure you copied 0.8.2 into res_mods, not into an existing 0.8.2 folder.
- There must NOT be a mod_offhangar.pyc beside mod_offhangar.py.
- Do NOT delete scripts\client\CameraNode.pyc or OfflineEntity.pyc.
- Check <game folder>\python.log for:

  Offline Battles source loader active; LAN settings and prebaked navigation enabled

See INSTALL.txt for the feature summary and LAN_SERVER.md for detailed network
diagnostics and limitations.
